# Implementation contract
Package com.wonderplay. App name wonderPlay. Root owns Models.kt, Gradle, app bootstrap/MainActivity/AppViewModel, docs, resources, CI and final integration.

Data agent owns data/**, metadata/**, source/**, data/domain tests. Expose LibraryRepository(context): LibraryStore and SourceRegistry(context, library: LibraryStore) with suspend search(query,offset=0): SearchResult, resolvePlayback(track): PlaybackSource, getArtist(track): Artist, getAlbum(track): MusicCollection, getRelatedTracks(track): List<Track>, importLocal(uri: android.net.Uri): Track. Registry uses Audius full public non-gated tracks + user-selected local content. YouTubeMusicSource provides validated external links; never pretends YouTube audio works inside app. Room, DataStore, okhttp, org.json available. ArtworkResolver can enrich canonical artwork asynchronously without blocking playback.

Player agent owns player/** and player tests. Expose PlayerController(context, library: LibraryStore, sources: SourceRegistry), val state: StateFlow<PlayerState>, connect(), release(), play(tracks: List<Track>, index: Int=0), togglePlayPause(), seekTo(positionMs:Long), next(), previous(), setShuffle(enabled:Boolean), setRepeat(mode:RepeatMode), addNext(track:Track), enqueue(track:Track), remove(index:Int), move(from:Int,to:Int), clearQueue(), retry(), playIndex(index:Int). PlaybackService : MediaSessionService uses shared app graph accessed via (application as WonderPlayApp).container where container.library: LibraryRepository and container.sources: SourceRegistry. Service owns ExoPlayer. Keep state single-source-of-truth, restore queue paused, cancellation safe, audio focus/noisy. All controller public methods non-suspend, launch in owned scope.

UI agent owns ui/** only (including ui/HapticsController.kt). Root exposes AppViewModel containing val ui: StateFlow<UiState>, val player: PlayerController, val settings: StateFlow<AppSettings>, val favorites/history/localTracks/playlists/recentSearches: StateFlow of respective lists. UiState fields query:String, searchTracks:List<Track>, searching:Boolean, searchError:String?, hasMore:Boolean, collection:MusicCollection?, artist:Artist?, detailLoading:Boolean, message:String?. VM methods search(String), loadMore(), retrySearch(), toggleFavorite(Track), createPlaylist(String), renamePlaylist(Long,String), deletePlaylist(Long), addToPlaylist(Long,Track), removeFromPlaylist(Long,String), movePlaylistTrack(Long,Int,Int), importLocal(List<Uri>), removeLocal(Track), openArtist(Track), openAlbum(Track), closeDetail(), updateSettings(AppSettings), clearHistory(), clearSearches(), clearArtworkCache(), dismissMessage(). VM properties are lifecycle collectable. Expose @Composable WonderPlayRoot(viewModel: AppViewModel). Root activity installs Compose and calls it. UI handles local tab, menus, sheets, document picker. Use icons material-icons-extended, Coil3 AsyncImage, Compose Material3 customized. No network in composition. Real functional flows only. Settings source info clearly describes Audius + local audio and external YouTube links. Detail grouping local available where remote absent.

Models are in domain/Models.kt; do not change contracts without coordinating. Android min26 compile36 target36, Kotlin2.3.0, Compose BOM2025.12.01, Media3 1.9.3, Room2.8.4, Coil3.3.0, OkHttp4.12.0. Tests JUnit4 + coroutines-test + Robolectric + Room testing + Compose UI.
